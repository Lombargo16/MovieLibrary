# Movie Library

**Автор:** Айрат Идрисов

## Описание

GUI-приложение для хранения информации о фильмах с возможностью:
- Добавления фильма (название, жанр, год, рейтинг)
- Фильтрации по жанру и году
- Сохранения/загрузки данных в JSON
- Валидации ввода (год — число, рейтинг 0–10)

## Требования

- Python 3.6+
- Модули: tkinter (входит в стандартную библиотеку)

## Запуск

```bash
python movie_library.py
